TCC – QCAP & PCC Claims Processing Automation

926Scenarios from 9 feature files
96%First-attempt pass rate
3Parallel workers, stable
150+ hrsManual regression saved per cycle

Challenge Question-driven claim workflows across Initial Processing, Legal Rep, Deficiency Queue, and Send to PM, with claims that had to be prepared and regressed by hand.

Approach Built a Playwright-BDD framework from scratch in TypeScript. It uses data-driven question-matrix feature files (Scenario Outlines with Excel data), shared page objects and step modules, DB reset scripts, and a cross-worker lock for collision-free parallel runs. AI agents generate test cases and scripts and heal failing tests through MCP Playwright.

Result 7 user stories automated with 94–100% suite pass rates. 72 of 74 defect codes matched the business rules. Consolidated HTML reports and an Excel evidence workbook give stakeholders traceability by tracking number, status, and defect code.
